# REGATTA_Package_Ella

- GBIF_Download, OBIS_Download, and Local_csv_download are all used to get species lists from a location and taxa of interest
- The output of each of the _download functions can be input into Dataset_combine to get a long species list as a .txt file for input to CRABS
- That .txt file along with [PART 2 ASSIGNMENT NONSENSE] can be input into Validate_local_assignments to generate a list of the species assignment of each ASV based on local and global databases
